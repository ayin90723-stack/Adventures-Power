## 概述

**冒险的力量** 是一个 Minecraft Forge 1.20.1 模组，以 **冒险旅程驱动能力成长**。力量不来自装备附魔，不来自等级数值——力量源于你走过的路、击败的敌人、征服的维度。

- 🎯 **10 个里程碑** — 从度过第一夜到获得鞘翅
- ⚡ **30 种内在能力** — 闪避、飞行、吸血、免死、真实伤害……全部可自由开关
- 🌟 **第 11 阶段「冒险者的觉醒」** — 全部 30 种能力获得觉醒强化（机制质变或数值强化）
- 🎛️ **全能力自由开关** — 按 P 键打开统一面板，想用什么自己决定
- 📦 **数据驱动里程碑** — 里程碑与解锁条件由数据包 JSON 定义，可自由定制
- ⚙️ **高度可配置** — 所有倍率、概率、持续时间均可在 TOML 配置文件中调整

## 冒险旅程

### 冒险饰品：旅程的见证者

首次登录时自动获得 **「冒险的开始」**，佩戴在 Curios 身体栏位。佩戴后激活冒险者身份，通过 P 键统一面板（冒险进度标签）或饰品 tooltip 查看里程碑进度与已解锁能力。

```
玩家首次登录
  ↓
自动获得「冒险的开始」→ 佩戴后激活冒险者身份
  ↓
逐步完成 10 个里程碑（任意顺序，P 键面板查看进度）
  ↓
全部里程碑达成 →「冒险的开始」自动进化为「冒险的终点」
  ↓
激活「冒险者的觉醒」—— 全部 30 种能力 + 觉醒强化
```

### 10 个里程碑

| 阶段 | ID | 名称 | 解锁条件 | 解锁能力 |
|:-----:|-----|------|---------|---------|
| 1 | `first_night` | 🌙 初次夜冕 | 在夜晚中存活到天明 | 灵巧、大地之力 |
| 2 | `first_death` | 💀 初尝败绩 | 第一次死亡 | 虚空踏步、休养生息 |
| 3 | `first_trade` | 🤝 初次交易 | 与村民完成一次交易 | 灵魂绑定、不动如山、加速 |
| 4 | `first_deep` | ⛏️ 初探地底 | 到达 Y<0 的深层世界 | 全视之眼、无形之手、磁吸 |
| 5 | `first_enchant` | ✨ 初次附魔 | 完成原版成就「附魔师」 | 不朽装备、鸿运当头、经验加成 |
| 6 | `nether` | 🔥 炽热之门 | 完成原版成就「进入下界」 | 环境免疫、嗜血、伤害抗性 |
| 7 | `wither` | 💀 凋零之陨 | 击杀凋零 | 禁疗之触、坚韧之躯、死亡抗拒 |
| 8 | `warden` | 👁️ 幽匿之惧 | 击杀监守者 | 受击坚韧、净魂、满载而归 |
| 9 | `dragon` | 🐉 终末之翼 | 完成原版成就「解放末地」 | 翱翔、淬魂之力、破敌之眼、恩赐永驻 |
| 10 | `elytra` | 🪶 苍穹之证 | 完成原版成就「天空是极限」 | 影杀、真实血量、拒绝篡改、旅者之力 |

> 里程碑解锁条件由数据包 `milestones.json` 驱动（原版成就或自定义触发器），支持 `/reload` 热更新与数据包自定义（`merge` 合并 / `enabled:false` 禁用 / `disabled_abilities` 能力黑名单），详见 `docs/datapack-guide.md`。

## 第 11 阶段：冒险者的觉醒

10 个里程碑全部达成且持有「冒险的终点」时自动激活。**全部 30 种能力**获得觉醒强化（机制质变或数值强化，见上表觉醒列），觉醒玩家的显示名会带金色称号前缀。

## 操作指南

| 按键 | 功能 |
|------|------|
| **P** | 冒险统一面板（Buff 永驻 / 能力配置 / 冒险进度，默认能力配置） |
| **空格（空中）** | 虚空踏步 — 二段跳（觉醒·御风：疾跑时朝视角冲刺） |
| **Y** | 切换主动技能（旅者审判 ⇄ 旅者庇护） |
| **G** | 释放当前选中的主动技能 |

所有按键可在原版「控制」设置中自定义。

### 主动技能

- **旅者审判**：对周围 6 格（觉醒 9 格）所有生物造成范围伤害（基础 10 点 + 每里程碑 3% 目标生命值），冷却 30 秒
- **旅者庇护**：短暂无敌 5 秒 + 清除所有负面效果，冷却 90 秒。觉醒后可缓慢移动（0.3× 速度）

## 安装

1. 安装 Minecraft Forge 1.20.1
2. 下载并安装 [Curios API](https://www.curseforge.com/minecraft/mc-mods/curios)（5.14.1+）
3. 将 `adventure_power-1.3.5.jar` 放入 `mods` 文件夹
4. 启动游戏，进入世界后自动获得「冒险的开始」

## 从源码构建

```bash
git clone https://github.com/ayin90723-stack/Adventures-Power.git
cd Adventures-Power
./gradlew build -x test
# 构件：build/libs/adventure_power-1.3.5.jar
```

**要求**：JDK 17，Curios API（通过 CurseMaven 自动拉取，见 `build.gradle`）。

## 配置文件

所有数值均可通过 `config/adventure_power.toml` 调整：

- 各能力的倍率、概率、持续时间
- 觉醒全局倍率（`awaken_multiplier`，默认 1.5）
- 各能力的觉醒独立配置项

修改配置后需重启游戏（或重启服务器）生效；里程碑数据包修改用 `/reload` 热更新。

## 常见问题

**Q: 能力太多了，可以关掉一部分吗？**
A: 可以。按 P 打开面板，每个能力旁边都有开关。

**Q: 死了 Buff 和经验会丢吗？**
A: 开启「灵魂绑定」后，死亡时保留全部正面 Buff；觉醒后经验也完全不掉落。

**Q: 里程碑进度存在哪里？**
A: 数据三层备份（Capability → 实体 NBT → 冒险饰品物品 NBT），死亡、换维度、登录都会自动恢复，不怕丢。

**Q: 和其他模组兼容吗？**
A: 核心机制通过 Mixin 在底层拦截，设计上考虑了模组环境兼容性（Boss 自定义无敌、战斗模组等）。遇到冲突欢迎反馈。

**Q: 可以在服务器使用吗？**
A: 可以。能力逻辑全部在服务端执行并校验，客户端仅用于 UI 显示和按键输入。

**Q: 想自定义里程碑或能力解锁条件？**
A: 通过数据包覆盖 `data/adventure_power/adventure_power/milestones.json` 即可，支持 `merge` 按 id 合并、`enabled:false` 整体禁用、`disabled_abilities` 能力黑名单，详见 `docs/datapack-guide.md`。
